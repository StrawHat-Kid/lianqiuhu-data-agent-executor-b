# HC 纯问数数据模板填写说明

请使用同目录的《HC纯问数数据采集模板.xlsx》整理业务数据。方案团队只需要整理数据和业务口径，不需要理解执行器、制作 `knowedge` 文件、编写 Prompt 或转换 CSV。

## 请怎样填写

1. 在“指标数据”中，一行只填写一个确定的数据事实。数字填在“数值”，单位填在“单位”，不要把它们写在同一个单元格。
2. 日期或期间统一使用 `YYYY-MM-DD`、`YYYY-MM` 或 `YYYY`。一个日期或时间段对应一条明确记录。
3. 指标名称相同但时间、对象、单位或口径不同，应拆分为不同记录。
4. 在“口径说明”中写清累计、日/月/年边界、同比/环比规则、统计范围、空值处理和特殊业务含义。
5. 在“典型问法”中填写常见问题与期望回答要点，用于后续测试；这些问题不会被硬编码进执行器。

## 可以同时提供的材料

如果已有原始 Excel 或 CSV，请与模板一起提供。原始文件有助于核对数据来源和口径。

## 请避免的做法

- 不要只提供截图、仪表盘图片或图表。
- 不要只通过单元格颜色表达业务含义；含义必须写入字段或备注。
- 不要把多个时间点、多个指标或多个单位混在一行。
- 不要省略单位、统计对象、时间范围或数据来源。
- 口径有歧义时，不要留给系统猜测，必须在“口径说明”中写明。

模板中的示例行均标记为“示例占位数据”，不是练秋湖真实业务数据。
